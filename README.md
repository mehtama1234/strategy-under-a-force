# Strategy Under a Force

Twenty plain-English collections on the forces reshaping how companies really make money.

**The method:** pick one big *force* → ask every company/sector *what did it make scarce, cheap, safe, risky, or newly valuable?* → group the answers → research → read the repeating patterns. Each collection is a small self-contained site: a grouped hub, ~13 write-ups, and a "patterns" synthesis.

**Start here:** open [`index.html`](index.html) — the master hub linking all 20.
